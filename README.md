
# ArchiVision 3D

A real-world architectural visualization studio built using Python and the Ursina Engine.

## Features
- 3D architectural visualization
- Interactive building design
- Lighting and shadow effects
- Save architectural designs
- Import and work with images

## Technologies
- Python
- Ursina Engine
- Panda3D
- Pillow

## Installation

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run the application

```bash
python archivision_v4_updated.py
```
